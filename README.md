`Ctrl + Alt + F2` --> Desktop GUI  
`Ctrl + Alt + F3` --> CLI  
`Ctrl + Alt + F1` --> GUI Ubuntu login  
`Ctrl + Alt + F4` --> new CLI session  
  
  
  
  
  
`~`  --> print where  
`pwd` -> prints the full path  
`ps` --> Process staus  
`clear` --> clears the screen (Shortcut `Ctrl + l`)  
  
  
  
`nano <filename.c>` / `vi <filename.c>` / `vim <filename.c>` --> creates a new c file & opens it  
`mkdir <folder_name> --> creates a new directory in the current location  
`rm <filename>` --> Removes the file  
`rm -rf <folder_name>` --> Force removes the whole directory along with subdirectories  
  
  
  
`gcc -o <output_name> <source_code_file_name.c>` --> Compiles the c code  
`./<output_name>` --> runs the compiled file
